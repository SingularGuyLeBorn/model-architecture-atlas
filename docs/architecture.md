# 结构模板与扩展

## 四个边界

1. **配置**：从官方配置提取维度、层数、专家数和压缩模式。V4.1 的文本配置位于 text_config，不能误用视觉参数。
2. **语义**：Recipe 包含 Stage 与显式 links。每条边写出 source、target、变量；独立分支位于同一拓扑层。
3. **布局**：React Flow 测量节点高度，layoutStages 用同层最大高度排下一层；不能按文字长度猜高度。
4. **渲染**：共享 Tensor、Vector、Projection、Parallel、Silu、Add 以及圆形 Σ。复制图元不是扩展模板的方式。

## 组件

- diagram-primitives.tsx：从原 V4.1 组件真正提取的公共图元，原图继续消费这些导出。
- MathMarkup.tsx：图内公式与连线标签共用的渲染边界。层号变化只更新同构 MathML 的文字；算子、属性或分数结构变化时整体替换。矩阵行列按位置保持身份，不用公式文本作为重建 key。
- structure-blocks.tsx：章节级结构模板。变量、维度同处标题；参数和激活分色；长末项分配更多列宽。
- EditableArchitectureGraph.tsx：正交避障、内部边界端口、透明大标签、端点拖动和历史接口。
- RecipeCanvas.tsx：语义节点的测量、拓扑排列、具名内部输入输出端口、定位、保存与撤销。
- DeepSeekV41Layer.tsx：已有详细层图的迁移基线。保留层切换、内部子节点与虚拟化。

## 新模型

1. 固定官方配置到一个提交 SHA；记录来源和日期。
2. 在 models.ts 注册模型并声明支持的章节。
3. 先复用现有机制模板；只为真实结构差异添加分支。
4. 新机制写成独立 Stage；公式放核对栏，图内保留矩阵、算子、分支与汇合。
5. 声明实际变量的 links，检查每个输出的来源与消费者。没有依赖的两个阶段不接线。
6. 添加配置边界和语义测试，再做浏览器端口、溢出、截图与性能检查。

示例：R1 / V3 / V3.1 共用 MLA 推理结构，训练章节独立；V4 的压缩器不能复用 V4.1 的跨层共享假设。

## 性能

只挂载当前模型当前章节。V4.1 大图独立懒加载；普通章节按视口挂载节点。公式缓存与路由缓存不依赖每一帧的视口变化。

浏览器测试记录鼠标事件进入到视口更新后首个 requestAnimationFrame 的时间。它衡量界面反馈，不是显示器光子延迟，也不是冷启动或完整大图重建时间。30ms 是平移反馈验收目标，不宣称所有设备、所有交互都已得到同样结果。

节点与边由画布的受控状态持有。原生拖动回调在本次输入内同步提交坐标；边编辑直接使用该状态的更新入口，不经过 React Flow 实例队列再生成差异回传。尺寸观察、初始化与程序化布局继续批处理，只有真实拖动及调整尺寸使用同步提交。路由算法、保存格式和一次手势一条撤销记录保持不变。

`e2e/interaction-budget.spec.ts` 分别测平移、滚轮平移、缩放、拖框和拖线，解释面板打开与关闭各一组。测试限制反馈 P95 和最大值不超过 30ms，同时统计未反馈输入；计时器不把抓取阈值内的旧输入归到后续移动。每次验收须使用生产构建，并单独运行性能组，避免与构建或其他浏览器测试争抢资源。

## 本地布局

布局与语义事实分开。保存内容包括节点坐标、尺寸和边，存入当前浏览器 localStorage；没有后台同步或账号绑定。存储失败必须有可见反馈。

## 内容层级

“全模型概览”展示阶段关系；机制章节展开输入、参数和运算；V4.1 的“逐层交互”进一步展开内部端口与每层缓存模式。导航图不能替代算子实现，也不能把训练分支当作推理中的必经步骤。
