- 缓存章节由单步例子扩展为九个步骤：进入前状态，以及两个 token 分别在第 3、4 层的局部更新、全局压缩、选行与 Attention。旧例的投影、行拼接、参数来源和 SVG 功能保留。
- 两层局部窗口分别淘汰 token 1、2，写后为 2–129、3–130；G 与索引 Key 从 64 行增至 65 行。图中展开暂存两槽、组内逐列权重、两条缓存写入分支和 G 行号与原 token 组的对应。
- 复用连线分别传递 G 和同一 token 的 ID；跨步连线仅传历史状态与候选暂存，不把上一 token 的第 4 层输出接成下一 token 的第 3 层输入。旁注和 skill 同步更新。

## 页面修复

- mHC 控制器避让完整 Compressor；测量同时核对层号和 Prefill/Decode，切换时不再使用上一模式的高度。
- RMSNorm 分母连线从两栏之间通过，不穿过输入矩阵；平方、累加、除法、加 epsilon、开方分别可见。
- SiLU 的 sigmoid 展开为取负、指数、加一、取倒数；z 旁路按内容定高，不随另一支路拉成长框。
- Attention 展开代表元素点积及包含 sink 的 Softmax 分母累加。Engram、Indexer 和 Compressor 的加权汇合使用圆形 Σ，已展示输入分别接入。
- 修复 Router 省略号和全局选行索引溢出；专家省略列宽度与实际出线位置使用同一尺寸。
- 模块导航补齐输入来源、归一化、Compressor、全局选择、KV 合并、系数控制器和专家汇总。

## 性能改动

- 自动布线按既有评分函数裁掉不可能胜出的候选；尺寸、端口及人工路径完全相同时复用路由，几何变化仍重新计算。
- 公式共享解析模板，每个显示对象保有独立 DOM；同结构公式只更新变化的文字。
- 去掉初次挂载中的重复同步测量，使用尺寸观察结果；累加器由 SVG 直接计算百分比坐标，不再逐个测宽再渲染。
- 切层直接更新受控图数据，减少转换与回传；解释面板延迟渲染屏幕外的文字区域。

### 连续操作

以下是最终完整回归的 P95，单位 ms。DOM 表示事件进入到样式更新；下一 rAF 是更新后的帧回调，**不是显示器实际呈现时间**。

| 操作 | 侧栏关闭 DOM / 下一 rAF | 侧栏打开 DOM / 下一 rAF |
| --- | ---: | ---: |
| 整画布拖动 | 1.0 / 2.5 | 1.4 / 3.6 |
| 滚轮平移 | 1.2 / 1.2 | 1.6 / 1.6 |
| 缩放 | 1.3 / 1.3 | 2.2 / 2.3 |
| 单框拖动 | 8.4 / 30.7 | 8.8 / 31.2 |

每轮分别执行 50 次整图拖动、30 次滚轮平移、25 次缩放及 40 次节点移动。帧间隔 P95 约 18.1ms；上一轮侧栏打开的整图拖动出现过 35.7ms 间隔，本轮最大 18.6ms。单独的整图 60 次拖动测试 P95 为 2.3ms，该场景最大帧间隔 27.1ms。

## 交互与复现

- 点框首次打开解释面板；手动关闭后，选择其他框不会重开；点击“显示解释”恢复。
- 桌面独立右栏，窄屏上下分区，不覆盖画布。画布滚轮平移，侧栏滚轮只滚动文字。
- mHC 四路同排，残差混合与输出加权左右并行，C 保持 4×4。大型分组透明，张量保留语义色。
- 重复运行：`pnpm lint`、`pnpm test`、`pnpm build`、`pnpm exec playwright test`。样本与截图输出到忽略的 `playwright-report`、`test-results`、`artifacts`，不提交运行产物。
- 按用户要求仅在本地维护，未推送，也未执行云端 CI。
